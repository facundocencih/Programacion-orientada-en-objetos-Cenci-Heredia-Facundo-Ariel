# Programacion orientada a objetos

Repositorio de ejercicios de la materia Programacion Orientada a Objetos de la Universidad Blas Pascal.

## Proyectos

- `ejercicio1`: login basico en Qt Widgets.
- `ejercicio2`: monitor de metricas consumiendo un endpoint HTTP.
- `ejercicio3`: pizarra de dibujo con sincronizacion remota.
- `ejercicio4`: proyecto en desarrollo, sin README por ahora.
- `ejercicio5`: ya cuenta con documentacion propia.
- `ejercicio6`: ya cuenta con documentacion propia.
- `ejercicio7`: login con clima, fondo remoto y ventana de perfil.
- `ejercicio-8`: editor multilenguaje con login, validacion y exportacion.
- `ejercicio9`: paint con login y persistencia en SQLite.
- `Ejercicio10`: juego tipo T-Rex runner con obstaculos y puntaje.

Cada proyecto documentado incluye una descripcion corta, funcionamiento general, requisitos, compilacion y uso.
